Solmar City is an original 2D top-down open-world crime game, built from scratch for make.fun's "Make GTA 6" bounty. Marlowe Vane arrives in Solmar City with forty dollars and a borrowed jacket. Explore a seeded procedural city on foot and by car, steal cars, outrun the Solmar police through a five-star wanted system, and run five story jobs — from a first stolen sedan to the big score at Solmar National Bank. Traffic and pedestrians fill the streets, the HUD tracks money, health, wanted stars and a live minimap, and every sound is synthesized with WebAudio. No assets from any commercial game; every name, character, street and sound is original.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, just static files under `game/`.
